# 전공 학습실

전공 수업 자료로 **공부 노트 → 암기카드 → 시험 문제 → 오답노트**까지 만드는 정적 웹앱입니다. 서버도 빌드도 없이 `index.html` 하나로 동작합니다.

연구 허브와 디자인·AI 연결·저장소를 함께 쓰도록 만들어져, 허브 라이브러리의 논문을 그대로 전공 자료로 가져올 수 있습니다.

## 하는 일

1. **자료함** — PDF·PPTX·DOCX·텍스트·이미지를 끌어다 놓으면 쪽·슬라이드 번호(`[p.N]`)까지 붙여 글자를 뽑습니다. 글자가 없는 스캔본은 이미지 인식으로 읽습니다. 과목·주차로 묶어 둡니다.
2. **공부 노트** — 한눈에 보기 → 핵심 개념(정의·기전·중요성·예시) → 용어표 → 비교표 → 시험 포인트 → 헷갈리는 것 → 스스로 점검 질문. 긴 자료는 나눠 읽은 뒤 합칩니다. 자료에 없는 내용은 `💡 보충:`으로 구분합니다.
3. **암기카드** — 노트에서 15~25장을 만들고, 맞히면 1 → 3 → 7 → 16 → 35일 뒤로 복습이 밀리는 간격 반복으로 외웁니다.
4. **퀴즈** — 객관식·OX·단답형·서술형, 난이도, 연습(바로 채점)/시험(제한 시간, 한 번에 채점). 여러 자료를 고르면 자료를 연결해야 풀리는 연관 문제 비율을 정할 수 있습니다. 단답·서술형은 동의어·표기 차이를 감안해 채점하고, 채점은 직접 뒤집을 수 있습니다.
5. **오답노트** — 틀린 문제가 개념별로 쌓이고, 다시 풀어 맞히면 사라집니다. 같은 개념을 다른 각도에서 묻는 유사 문제도 만듭니다.
6. **통합 노트** — 여러 주차를 묶어 개념 연결 지도와 공통점·차이점을 정리합니다.
7. **질문하기** — 자료를 근거로 묻고 답합니다.

## GitHub Pages로 올리기

1. GitHub에서 **New repository** → 이름 예: `study-room` → **Public** → Create
2. **Add file → Upload files**에서 이 폴더의 `index.html`·`README.md`를 끌어다 놓고 **Commit changes**
3. **Settings → Pages** → Source `Deploy from a branch`, Branch `main` / `(root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/study-room/` 에서 열립니다

무료 계정은 Public 저장소에서만 Pages를 쓸 수 있습니다. 코드만 공개되고 **자료는 각자의 브라우저에만** 저장되니, 공개 저장소여도 강의자료·노트는 올라가지 않습니다.

## 연구 허브와 함께 쓰기

허브와 학습실을 **다른 저장소로 따로 올려도 연동됩니다.** 브라우저 저장소(IndexedDB·localStorage)는 폴더나 저장소가 아니라 **사이트 주소의 앞부분(origin)** 으로 묶이기 때문입니다.

| 허브 주소 | 학습실 주소 | 라이브러리·API 키 공유 |
|---|---|---|
| `아이디.github.io/research-hub/` | `아이디.github.io/study-room/` | ✅ 같은 origin |
| `아이디.github.io/research-hub/` | `다른아이디.github.io/study-room/` | ❌ → 백업 JSON으로 옮기기 |
| 사용자 도메인 `hub.example.com` | `아이디.github.io/study-room/` | ❌ → 백업 JSON으로 옮기기 |

### 서로 오가는 바로가기

- **허브 → 학습실**: 허브 nav의 `전공 학습실 ↗`. 기본 주소는 `../study-room/`이라, 저장소 이름을 `study-room`으로 하면 설정 없이 바로 이어집니다. 이름이 다르면 처음 누를 때 주소를 묻고 그 브라우저에 기억합니다. 바꾸려면 **Shift+클릭**.
- **학습실 → 허브**: 학습실 **설정**(또는 연구 허브 연동 화면)에 허브 주소를 넣으면 헤더에 `연구 허브 ↗`가 생깁니다.

### 허브 논문 가져오기

학습실의 **연구 허브 연동** 화면에서 허브 라이브러리의 논문을 골라 가져옵니다. 제목·서지·초록·한글 요약·연구 노트·용어·Figure 설명을 묶어 하나의 자료로 만듭니다. 초록도 요약도 없는 기록은 공부할 내용이 없어 건너뜁니다.

## AI 연결

쓸 수 있는 것을 이 순서로 자동으로 고릅니다.

1. **claude.ai에서 열었을 때** — 설정 없이 바로 동작
2. **Anthropic API 키** — 설정에 넣으면 GitHub Pages에서도 자동 실행
3. **Google AI 키** — 대안
4. **복사·붙여넣기** — 키 없이도 모든 기능 사용. 질문을 복사해 Claude에 붙이고, 답을 되돌려 붙이면 됩니다

키는 **이 브라우저에만** 저장됩니다(`localStorage`의 `hub:cfg`, 허브와 같은 칸). 공개 저장소이니 **키를 HTML에 적어 커밋하지 마세요.**

## 자료 보관과 백업

| 환경 | 보관 위치 |
|---|---|
| GitHub Pages·로컬 파일 | 이 브라우저의 IndexedDB (`research-hub-more`, 허브와 칸만 나눠 씀) |
| claude.ai | 로그인한 계정의 저장소 |
| 저장소를 못 쓸 때 | 이번 방문 동안만 |

브라우저 저장소는 기기·브라우저마다 따로이고, 시크릿 창이나 데이터 삭제로 사라질 수 있습니다. **설정 → 백업 내려받기**로 JSON을 받아 두고, 다른 기기에서는 **백업 가져오기**로 넣으세요. 시험 전에는 한 번 받아 두는 편이 안전합니다.
