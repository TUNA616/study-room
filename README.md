# 전공 학습실

전공 수업 자료로 **공부 노트 → 암기카드 → 시험 문제 → 오답노트**를 만들고, 강연 보고서·리포트·발표 자료 같은 **과제 초안**까지 만드는 정적 웹앱입니다. 서버도 빌드도 없이 `index.html` 하나로 동작합니다.

연구 허브와 디자인·AI 연결·브라우저 저장소를 함께 쓰도록 만들어져, 허브 라이브러리의 논문을 그대로 전공 자료로 가져올 수 있습니다.

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| 홈 | 현황, 오늘 복습할 카드, 최근 퀴즈, 연결 상태 |
| 자료함 | 강의자료 올리기·과목/주차로 묶기, 자료마다 공부 노트·암기카드·질문하기·원문·원본 |
| **자료 만들기** | 강연 보고서, 과제 리포트, 발표 자료, 요약본, 논문 발제, 문헌 리뷰, 실험 보고서 초안 → Word·PowerPoint |
| 퀴즈 | 객관식·OX·단답·서술형 출제와 채점 |
| 오답노트 | 틀린 문제를 개념별로 모아 다시 풀기 |
| 암기카드 | 간격 반복 복습 |
| 연구 허브 연동 | 허브 라이브러리의 논문을 자료로 가져오기 |

## 공부하기

1. **자료함** — PDF·PPTX·DOCX·텍스트·이미지를 끌어다 놓으면 쪽·슬라이드 번호(`[p.N]`)까지 붙여 글자를 뽑습니다. 글자가 없는 스캔본은 이미지 인식으로 읽습니다. 올린 **원본 파일도 그대로 보관**됩니다.
2. **공부 노트** — 한눈에 보기 → 핵심 개념(정의·기전·중요성·예시) → 용어표 → 비교표 → 시험 포인트 → 헷갈리는 것 → 점검 질문. 자료에 없는 내용은 `💡 보충:`으로 구분합니다.
3. **암기카드** — 노트에서 15~25장을 만들고, 맞히면 1 → 3 → 7 → 16 → 35일 뒤로 복습이 밀립니다.
4. **퀴즈** — 난이도, 연습(바로 채점)/시험(제한 시간), 여러 자료를 엮은 연관 문제. 단답·서술형은 동의어·표기 차이를 감안해 채점하고, 채점은 직접 뒤집을 수 있습니다.
5. **오답노트** — 다시 풀어 맞히면 사라지고, 같은 개념의 유사 문제를 만들어 줍니다.
6. **통합 노트**·**질문하기** — 여러 주차를 엮어 정리하고, 자료를 근거로 묻고 답합니다.

## 자료 만들기 (수업·과제 자료)

자료함의 강의자료·논문과 **내 메모**로 초안을 만듭니다. 자료 없이 메모만으로도 됩니다.

| 양식 | 구성 | 기본 분량 | 내보내기 |
|---|---|---|---|
| 강연·수업 보고서 | 강의내용 및 배운점 / 고찰 | A4 1장 | Word |
| 과제 리포트 | 서론 · 본론 · 결론 · 참고자료 | A4 2장 | Word |
| 발표 자료 | 슬라이드별 제목 · 핵심 · 발표자 노트 | 12장 | PowerPoint |
| 한 장 요약본 | 핵심 개념 · 기전 · 비교표 · 외울 것 · 함정 | A4 1장 | Word |
| 논문 발제 | 배경 · 주장 · 방법 · Figure별 결과 · 비판 · 토론 질문 | A4 2장 | Word |
| 문헌 리뷰 | 주제별 종합 · 비교표 · 연구 공백 | A4 3장 | Word |
| 실험 보고서 | 목적 · 원리 · 재료와 방법 · 결과 · 고찰 · 결론 | A4 2장 | Word |
| 직접 지시 | 내가 적은 양식 그대로 | 선택 | Word |

- **분량·문체·언어** — A4 반 장~5장(발표는 8~20장), 보고서체·개조식·경어체, 한국어·English·국문+영문 초록. 만든 뒤 글자 수(공백 포함/제외)와 목표 분량을 비교해 보여 줍니다.
- **지어내지 않기** — 확인할 수 없는 수치·인용문·문헌은 만들지 않도록 했습니다. 참고자료에는 고른 자료의 서지만 들어가고, 자료가 없으면 `[참고문헌 입력]` 자리만 둡니다. 실험 보고서의 결과는 메모에 적은 데이터만 쓰고, 없는 값은 `[데이터 입력]`으로 남깁니다.
- **고쳐 쓰기** — "A4 1장에 맞게", "고찰을 더 깊게", "더 자연스럽게" 같은 버튼이나 직접 적은 지시로 다시 씁니다. 직접 고치기도 되고, 이전 6개 버전까지 되돌릴 수 있습니다.
- **내보내기** — Word(.docx, A4·맑은 고딕 11pt·제목 스타일 적용), PowerPoint(.pptx, 16:9·발표자 노트·그림 자리 표시), 글만 복사(한글·워드에 붙여넣기용), 마크다운.

만든 글은 **초안**입니다. 사실 관계와 출처를 확인하고, 내 생각과 말로 다듬어 제출하세요.

## 원본 파일 보관

올린 PDF·PPTX·DOCX·이미지의 **원본이 이 브라우저에 그대로 보관**됩니다. 자료의 **원문** 탭에서 원본을 열거나 내려받을 수 있습니다.

- 한 파일 150MB까지 보관합니다.
- 원본 보관 기능 전에 올린 자료나 붙여넣은 자료는 **원본 파일 붙이기**로 나중에 붙여 둘 수 있습니다.
- 처음 원본을 보관할 때 브라우저에 "이 사이트 데이터를 지우지 말아 달라"고 요청합니다(브라우저가 허락하면 **설정**에 '고정됨'으로 표시).
- 원본은 크기 때문에 **기기마다 따로** 있습니다. 다른 기기로 옮기려면 아래 .zip 백업을 쓰세요.

> 원본을 GitHub 저장소에 올리는 방식은 쓰지 않습니다. 공개 저장소라 강의자료가 그대로 공개되고, 브라우저에서 저장소에 쓰려면 GitHub 토큰을 페이지에 넣어야 하기 때문입니다.

## 백업과 기기 옮기기

**설정 → 자료 보관**에서 고릅니다.

| 백업 | 들어 있는 것 | 언제 |
|---|---|---|
| **백업 .zip (원본 포함)** | 자료·원문·노트·카드·퀴즈·오답노트·만든 자료 + `files/`에 원본 파일 | 기기를 옮기거나, 시험·제출 전에 안전하게 |
| 가벼운 백업 .json | 원본 파일을 뺀 나머지 전부 | 원본은 이미 있고 글·기록만 옮길 때 |

다른 기기에서는 **백업 가져오기**로 .zip이나 .json을 고르면 됩니다(.zip은 풀지 않고 그대로). 브라우저 저장소는 시크릿 창이나 브라우저 데이터 삭제로 사라질 수 있으니, 중요한 시기 전에는 .zip을 한 번 받아 두세요. 설정 화면에서 보관 중인 원본 수와 이 사이트가 쓰는 공간을 볼 수 있습니다.

## GitHub Pages로 올리기

1. GitHub에서 **New repository** → 이름 예: `study-room` → **Public** → Create
2. **Add file → Upload files**에서 이 폴더의 `index.html`·`README.md`를 끌어다 놓고 **Commit changes**
3. **Settings → Pages** → Source `Deploy from a branch`, Branch `main` / `(root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/study-room/` 에서 열립니다

무료 계정은 Public 저장소에서만 Pages를 쓸 수 있습니다. 공개되는 것은 코드뿐이고, **자료와 원본 파일은 각자의 브라우저에만** 저장됩니다.

## 연구 허브와 함께 쓰기

허브와 학습실을 **다른 저장소로 따로 올려도 연동됩니다.** 브라우저 저장소는 폴더나 저장소가 아니라 **사이트 주소의 앞부분(origin)** 으로 묶이기 때문입니다.

| 허브 주소 | 학습실 주소 | 라이브러리·API 키 공유 |
|---|---|---|
| `아이디.github.io/research-hub/` | `아이디.github.io/study-room/` | ✅ 같은 origin |
| `아이디.github.io/research-hub/` | `다른아이디.github.io/study-room/` | ❌ → 백업으로 옮기기 |
| 사용자 도메인 `hub.example.com` | `아이디.github.io/study-room/` | ❌ → 백업으로 옮기기 |

- **허브 → 학습실**: 허브 nav의 `전공 학습실 ↗`. 기본 주소는 `../study-room/`이라 저장소 이름을 `study-room`으로 하면 바로 이어집니다. 이름이 다르면 처음 누를 때 주소를 묻고 기억합니다. 바꾸려면 **Shift+클릭**.
- **학습실 → 허브**: 학습실 **설정**(또는 연구 허브 연동 화면)에 허브 주소를 넣으면 헤더에 `연구 허브 ↗`가 생깁니다.
- **허브 논문 가져오기**: 연구 허브 연동 화면에서 논문을 골라 가져오면 제목·서지·초록·한글 요약·연구 노트·용어·Figure 설명이 하나의 자료가 됩니다. 초록도 요약도 없는 기록은 건너뜁니다.

## AI 연결

쓸 수 있는 것을 이 순서로 자동으로 고릅니다.

1. **claude.ai에서 열었을 때** — 설정 없이 바로 동작
2. **Anthropic API 키** — 설정에 넣으면 GitHub Pages에서도 자동 실행
3. **Google AI 키** — 대안
4. **복사·붙여넣기** — 키 없이도 모든 기능 사용. 질문을 복사해 Claude에 붙이고, 답을 되돌려 붙이면 됩니다

키는 **이 브라우저에만** 저장됩니다(`localStorage`의 `hub:cfg`, 허브와 같은 칸). 공개 저장소이니 **키를 HTML에 적어 커밋하지 마세요.**
